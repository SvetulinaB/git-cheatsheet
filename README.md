# Шпаргалка по Git



## Инициализация и настройка

- `git init` — создать новый локальный репозиторий.

- `git config --global user.name "Имя"` - указать имя или никнейм автора.

- `git config --global user.email "email@example.com"` - указать почту.



## Основные команды

- `git status` - посмотреть текущее состояние файлов.

- `git add .` - добавить все изменения в "черновик" коммита.

- `git add FILE.txt` - добавить изменения только в конкретный файл FILE.txt.

- `git add папка/` - добавить изменения в конкретную папку.

- `git commit -m "Текст"` - сохранить изменения. "Текст" - это комментарий к исправлениям.

- `git log` - лог (история коммитов).

- `git log --oneline` - сокращенный лог.



## Работа с GitHub

- `git remote add origin <ссылка>` - привязать удаленный репозиторий.

- `git push` - отправить изменения на GitHub.



## Навигация по файловой системе

- `pwd` - показать текущую директорию (полный путь).

- `ls` - показать содержимое текущей папки.

- `ls -a` - показать содержимое папки, включая скрытые файлы.

- `cd <имя папки>` - перейти в указанную папку.

- `cd ..` - перейти на уровень выше (в родительскую папку).

- `cd ~` - перейти в домашнюю директорию.

- `cd /` - перейти в корневую директорию.



## Создание папок и файлов

- `mkdir <имя папки>` - создать новую папку.

- `touch <имя файла>` - создать новый пустой файл.



## Копирование и перемещение

- `cp <имя файла> <куда копировать>` - скопировать файл.

- `mv <имя файла> <куда переместить>` - переместить файл.



## Чтение файлов

- `cat <имя файла>` - вывести содержимое файла в терминал.



## Удаление

- `rm <имя файла>` - удалить файл.

- `rm -r <имя папки>` - удалить папку со всем содержимым.

- `rm -rf <имя папки>` - принудительно удалить папку без подтверждения.

### Понятия

- **Терминал (консоль, командная строка)** - это программа для управления компьютером с помощью текстовых команд. В Windows это GitBash, cmd, PowerShell и т.д.

- **Ветка (branch)** - это указатель на определенный коммит.

- **Коммит (commit)** - сохраненное состояние проекта.

- **Репозиторий (repository)** - папка с вашим проектом, за изменениями в которой следит Git. Бывает *локальный* (на вашем компьютере) и *удалённый* (на GitHub).

- **Git и GitHub** - это не одно и то же. *Git* - программа на вашем компьютере, которая отслеживает изменения. *GitHub* - это веб-сайт, где хранятся репозитории.

- **Хеш (hash)** - основной идентификатор коммита, который позволяет узнать его автора, дату и содержимое закоммиченных файлов (как "отпечаток пальца"). Все хеши, а также таблицу соответствий *хеш - информация о коммите* Git хранит в папке `.git`.

- **Лог (log)** - история всех коммитов в репозитории (от новых к старым). 


### Полезные возможности

- Команды необязательно печатать и выполнять по очереди. Можно указать их списком - разделить двумя амперсандами (`&&`).

- У консоли есть собственная память - буфер с несколькими последними командами. По ним можно перемещаться с помощью клавиш со стрелками вверх (↑) и вниз (↓).

- Чтобы не вводить название файла или папки полностью, можно набрать первые символы имени и дважды нажать `Tab`. Если файл или папка есть в текущей директории, командная строка допишет путь сама.

- *Прервать* выполнение текущей команды можно с помощью `Ctrl + C`. Спасает, если терминал "завис" или вы застряли в каком-то режиме.

- Если нужно передать последний коммит, то вместо хеша можно просто написать слово `HEAD` - Git поймёт, что вы имели в виду последний коммит.
